Почему Object URL не открывается, хотя мы владеем бакетом?
Потому что объект не является публичным. Для доступа необходим авторизованный запрос или подписанный URL.

Что на самом деле создаёт Create folder?
Amazon S3 — объектное, а не традиционное файловое хранилище. Папки являются логическими префиксами ключей. Кнопка Create folder обычно создаёт пустой объект с ключом uploads/, благодаря которому папка отображается даже без файлов.

Обращается ли aws s3 presign к S3 для создания ссылки?
Нет. AWS CLI формирует криптографическую подпись локально, используя доступные учётные данные. S3 проверяет её только при обращении по сформированной ссылке.
