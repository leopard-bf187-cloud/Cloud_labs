# ADR-0001. Развёртывание приложения с помощью deploy.sh

- Статус: принято
- Дата: 2026-10-02

## Контекст

Приложение Mood Diary развёртывается на экземпляре Amazon EC2 с Amazon Linux 2023.

Исходный код хранится в публичном репозитории GitHub. На сервере используются nginx, PHP-FPM и PostgreSQL.

Необходимо выбрать способ доставки новых версий приложения на сервер. Процесс должен быть достаточно простым для учебного проекта, воспроизводимым и не требовать ручного копирования отдельных файлов.

## Решение

Для развёртывания используется скрипт `deploy.sh`, расположенный на сервере EC2.

Скрипт выполняет следующие действия:

1. Переходит в каталог `/var/www/mood-diary`.
2. Получает новую версию исходного кода командой `git pull --ff-only`.
3. Устанавливает PHP-зависимости через Composer.
4. Применяет миграции базы данных.
5. Перезагружает PHP-FPM.

Скрипт запускается с локального компьютера через SSH:

```bash
ssh -i <key>.pem ec2-user@<Public-IP> ./deploy.sh
```
